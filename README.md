# NutriAI - 맞춤형 식단 관리 서비스 프로젝트 (7주차 최종본)

## 📌 1. 서비스 개요
- **서비스 목적:** 바쁜 현대인들을 위해 개개인의 목표에 맞춘 일일 식단을 분석하고 제공
- **주요 사용자 (Target User):** 일상 속에서 건강한 식습관을 유지하고 싶거나 다이어트/벌크업을 원하는 직장인 및 학생
- **배포 주소:** https://12507055-alt.github.io/my-first-webpage/

## 📌 2. 인터랙션 시나리오 및 사용자 흐름

### 🎯 핵심 행동 및 완료 조건
- **사용자 목표:** 나에게 맞는 7일 무료 식단 리포트를 신청한다.
- **핵심 행동:** 이름, 이메일, 건강 목표를 폼에 작성하고 제출한다.
- **완료 조건:** 입력한 데이터를 확인창에서 점검한 뒤, '최종 신청 완료' 버튼을 눌러 완료(Success) 화면을 확인한다.

### 🔄 사용자 흐름 (User Flow 4단계)
1. **[시작/입력] (Step 1):** 사용자가 무료 체험 신청 폼에 접속하여 정보를 입력.
2. **[검사/오류] (Step 1):** 필수값(이름, 이메일, 목표) 누락 시 빨간색 안내 문구로 수정을 요구.
3. **[확인/수정] (Step 2):** 유효한 입력 시, 입력된 정보(이름, 이메일, 목표)를 요약하여 보여줌.
   - 수정이 필요하면 '이전' 버튼을 눌러 작성된 데이터가 유지된 채로 Step 1로 돌아감.
4. **[완료/초기화] (Step 3):** '최종 신청' 클릭 시 완료 인사말 표시. '다시 시작' 버튼 클릭 시 폼과 피드백 상태가 완전히 초기화되어 Step 1로 복귀.

## 📱 3. 테스트 결과 (반응형 점검)
개발자 도구를 활용하여 화면 크기별 조작과 흐름을 테스트 완료했습니다.
- **1100px (데스크톱):** Step 1~3의 모달/섹션 전환이 가로 레이아웃 붕괴 없이 깔끔하게 작동함.
- **768px (태블릿):** 네비게이션이 세로로 변경되며, 확인창(Step 2)의 이전/완료 버튼이 화면 비율에 맞춰 정렬됨.
- **390px (모바일):** 폼 입력창, 확인 텍스트, 하단 전환 버튼(flex-direction: column 적용)이 화면에 가득 차게 보여지며 스크롤이나 잘림 현상 없이 손가락 조작이 원활하게 작동함.
