# NutriAI - 맞춤형 식단 관리 서비스 프로젝트 (중간고사 프로토타입)

## 📌 1. 서비스 개요
- **서비스 목적:** 바쁜 현대인들을 위해 개개인의 목표에 맞춘 일일 식단을 분석하고 제공
- **주요 사용자:** 일상 속에서 건강한 식습관을 유지하고 싶거나 다이어트/벌크업을 원하는 직장인 및 학생
- **배포 주소:** https://12507055-alt.github.io/my-first-webpage/

## 💡 2. 중간고사 추가 구현 기능: [나의 신청 내역 누적 및 취소 기능]
7주차의 '입력 → 확인 → 완료' 흐름 마지막(Step 3)에 **완료된 신청을 목록으로 누적 저장하고, 원할 경우 개별 내역을 취소(삭제)하여 상태를 변경할 수 있는 기능**을 추가했습니다.

## 🔄 3. 사용자 흐름 및 인터랙션 시나리오
1. **[시작/입력] (Step 1):** 폼에 정보(이름, 이메일, 목표) 입력. 누락 시 오류 메시지 노출.
2. **[확인/수정] (Step 2):** 유효한 입력 시 요약 정보 확인. '이전' 클릭 시 기존 값 유지.
3. **[완료/누적] (Step 3):** '최종 신청 완료' 클릭 시 신청 데이터가 고유 ID와 함께 배열에 저장되며 **[나의 전체 신청 내역]** 목록에 추가됨.
4. **[취소 조건 검사/결과 없음] (새로운 행동):** 
   - 목록에 노출된 개별 '신청 취소' 버튼을 누르면 해당 내역이 배열에서 삭제되고 화면이 갱신됨.
   - 남은 내역이 0개가 되면 "현재 누적된 신청 내역이 없습니다."라는 빈 상태(Empty State) 피드백 제공.
5. **[초기화] (추가 경로):** '추가 신청하기(초기화)' 버튼을 누르면 내역은 보존된 채 Step 1 폼만 초기화되어 다중 신청이 가능함.

## 📱 4. 테스트 결과 기록 (반응형 및 분기 점검)
- **정상 경로 테스트:** 데이터를 다르게 3번 연속 신청해 본 결과, 3개의 개별 리스트가 겹침 없이 순차적으로 아래로 잘 누적되는 것을 확인.
- **취소 및 결과 없음 경로 테스트:** 누적된 항목의 '신청 취소' 버튼을 클릭 시 실시간으로 삭제가 반영되며, 전부 지웠을 때 정상적으로 빈 화면 회색 알림 박스가 출력됨.
- **모바일 환경(390px) 점검:** 
  - 내역 리스트의 아이템(텍스트)과 우측 취소 버튼이 가로로 겹치지 않도록 `flex-direction: column`으로 안전하게 세로 재배치 됨. 
  - 에러 없이 모든 기능 터치 조작 가능.
