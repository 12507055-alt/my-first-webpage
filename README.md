# NutriAI 서비스 소개 웹페이지 (6주차 과제)

## 📌 추가된 JavaScript 기능 설명

### 1. 탭 UI 구현 (`click` 이벤트)
- **동작 방식:** 사용자가 '추천 식단 미리보기' 영역에서 3개의 탭(다이어트/벌크업/건강유지) 중 하나를 클릭하면 발생합니다.
- **화면 변화:** 
  1. 클릭된 버튼의 배경색이 초록색으로 변경됩니다(버튼 스타일 변화).
  2. 선택된 탭과 연결된 식단 설명 콘텐츠만 화면에 표시됩니다(콘텐츠 표시 상태 변화).

### 2. 이름 입력 실시간 피드백 (`input` 이벤트)
- **동작 방식:** 폼에서 이름을 입력(타이핑)할 때마다 실시간으로 발생합니다.
- **화면 변화:** 
  1. "반갑습니다, [이름]님!" 이라는 맞춤형 환영 문구가 표시됩니다(문구 변화).
  2. 글씨 색상이 강조된 초록색으로 변경됩니다(스타일 변화).

### 3. 목표 선택 맞춤 메시지 (`change` 이벤트)
- **동작 방식:** 건강 목표 `<select>` 박스의 항목을 변경할 때 발생합니다.
- **화면 변화:** 
  1. 선택한 목표에 맞는 식단 추천 안내 문구가 등장합니다(문구 변화).
  2. 다이어트(파란색), 벌크업(핑크색), 건강(초록색) 등 선택 항목에 따라 알림 박스의 배경색과 글자색이 다르게 변합니다(스타일 변화).

### 4. 폼 제출 피드백 (`submit` 이벤트)
- **동작 방식:** '무료 체험 신청하기' 버튼을 클릭하여 폼을 제출할 때 발생합니다.
- **화면 변화:**
  1. 하단에 완료 안내 문구가 표시됩니다(문구 변화).
  2. 제출 버튼의 텍스트가 '신청 완료됨'으로 바뀌고, 색상이 회색으로 변경되며 비활성화됩니다(버튼 상태 및 스타일 변화).

## 📱 반응형 웹 테스트 결과
크롬 개발자 도구를 활용하여 기기 사이즈별 작동을 점검했습니다.
- **1100px (PC):** 가로 메뉴와 3열 기능 카드, 가로 탭 버튼 모두 정상 배치 및 기능 작동 확인.
- **768px (태블릿):** 네비게이션이 세로로 변경되고, 탭 버튼과 폼 레이아웃이 화면에 맞게 재정렬되며 화면 잘림 없이 작동 확인.
- **390px (모바일):** 가로 스크롤 현상이 없으며, 탭 UI 및 입력창이 모바일 화면 너비 100%에 맞춰 가독성 있게 동작함 확인.
